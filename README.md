# go-rplidar-sdk-handler

Handler for the RPLiDAR SDK programs, for Go projects.

**Note:** This repository is archived and read-only.

## Features

- **`Handler`** — interface to run the SDK programs, wait until ready, start and stop measurements, read them from a channel or as a 360-slot array, and get average distances by angle or cardinal direction.
